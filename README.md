# Español-Trainer

A single-file Spanish course (A1–B2) for GitHub Pages.

- `index.html` is the whole app: lessons, vocabulary, exercises, dialogues, readings, speaking and writing.
- `apple-touch-icon.png` is the home-screen icon.

There are no audio files. Every text is read aloud by the device's own Spanish voice (browser speech synthesis). For the best sound, install a voice from Spain: on iPhone, Mónica and Jorge in the Enhanced version (Settings › Accessibility › Spoken Content › Voices › Spanish (Spain)); on Windows, use Edge (Elvira and Álvaro); on Android, Google TTS with Spanish (Spain).
